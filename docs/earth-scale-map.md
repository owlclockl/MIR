# Карта мира в масштабе Земли

Основная карта игры использует собственный процедурный генератор (`src/gen/`).
Её поверхность — прямоугольный вымышленный мир размером **40 075 017 ×
20 003 932 м**: совпадает масштаб с Землёй, но реальные материки не
импортируются. Игрок сразу попадает на эту карту; отдельного интерфейса
блочного среза или переключателя ярусов нет. Внутренняя колонковая модель
сохраняет вертикальные слои для геологии и будущих игровых механик.

## Размер и деталь

Размер поверхности хранится явно в слоте вместе с seed. При одинаковых
параметрах генератор выдаёт тот же мир на разных устройствах. Полный растр
земной поверхности содержит около **8 × 10^14** метровых ячеек и не хранится
целиком: колонка вычисляется по координате, а вид выбирает подходящий шаг
клетки, считает строки порциями по бюджету кадра и постепенно уточняет
изображение. На максимальном приближении масштаб достигает одного метра на
пиксель.

Камера ограничена прямоугольными границами мира. Масштабная линейка, координаты,
широта и долгота используют метры и километры из того же источника размеров,
что и генератор; высота в строке состояния дана в метрах над уровнем моря.

## Основная карта и дополнительные виды

Основной вид рисует данные собственного генератора: биомы, рельеф, материки,
климат, осадки и деревни. Он не ждёт запуска Azgaar и не берёт у него берега,
климат или высоты.

Редактор **Azgaar** остался отдельным дополнительным видом. При создании слота
он получает `seed`, `width`, `height`, `points=1000000` и `options=default`;
web/PWA загружает редактор из `/fmg/`, а однофайловые сборки встраивают его в
приложение. Это самостоятельный документ, не источник данных основной карты.

Вид **«Планета»** — ещё один дополнительный вариант масштаба Земли: собственная
тайловая модель с геологией, климатом и живым временем. Когда открывается,
приложение поднимает Azgaar для возможности снять его географию, но вид планеты
может начать с собственной процедурной основы и не блокирует основную карту.
Страница `/planet.html` остаётся мастерской для этого модуля.

Слоты прежних версий с обзорными размерами (1280 × 800, 1600 × 1000,
1920 × 1080) по-прежнему поддерживаются `normalizeWorldConfig`; они открываются
как самостоятельные размеры процедурного мира.

## Проверки

- `npm run test:gen` — границы и детерминированность мира, материки, климат,
  гидрология, слои колонок, геологические данные и стоимость выборок.
- `npm run test:world-map` — слои и состояние основной карты, масштаб,
  панорамирование у края, материки, точка появления и снятие вида.
- `npm run test:ui` — проверка интерфейса: основная карта открывается первой,
  Azgaar загружается только при выборе, а игрок и мастер получают подходящие
  панели редактора.
