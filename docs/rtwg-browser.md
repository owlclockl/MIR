# RTWG в MIR: браузерный порт

> **Основной режим обновлён:** [единая Планета](unified-planet.md).
> Отдельные виды ниже — архивные инструменты `?mapTools=1`. Обычный экспорт
> `.sages-planet.json` сохраняет отображаемую географию, не только seed.


Дата: 2026-10-14. Пользователь явно выбрал **перенос RTWG**, не Terra и не
смешивание восьми альтернативных генераторов. Это новый подключённый сторонний
генератор/симулятор, не восстановление удалённого `src/gen/`.

## Как открыть

1. Открыть мир мастером и нажать **RTWG** в верхней панели.
2. По умолчанию — 2D сверху, сетка 256×128, симуляция на паузе.
3. **Запуск**, **Шаг** и **32 шага плит** управляют симуляцией. Последняя кнопка
   временно включает тектонику, затем возвращает прежний режим.
4. В правой панели — все восемь этапов, их параметры, включение/отключение,
   сброс полей; параметры плит, перезапуск и новое возмущение ветра.
5. **3D-обзор** — дополнительная диагностика: орбита мышью, Shift+мышь — сдвиг,
   колесо — дистанция, WASD — перемещение. Основная метровая карта остаётся сверху.
6. **Рельеф → редактор** требует подтверждения. Прежняя география заменяется
   только после этого; Azgaar пересчитывает свои реки, биомы и общественные данные.
   Это перенос рельефа, а не точное копирование температур/рек RTWG в Azgaar.

Смена вида при открытом мире сохраняет RTWG и приостанавливает скрытую симуляцию.
При выходе из мира GPU/WASM освобождаются. Для сохранения результата между
запусками используйте **Сохранить RTWG**, а не рассчитывайте на seed слота.

## Что действительно перенесено

| RTWG | Исполняемая реализация MIR |
|---|---|
| Начальная генерация | Оригинальный `FractalGenerator` с libnoise Perlin/NoiseMapBuilderPlane |
| Тектоника | Оригинальные C++ RTplatec: lithosphere, plate, movement, collisions, subductions, folding, aggregation, regeneration; WebAssembly |
| Rock | Оригинальный GPU-шейдер термической эрозии и потери породы в почву |
| Soil | Оригинальный GPU-шейдер водной эрозии, переноса и диффузии |
| Water | Оригинальный GPU-шейдер потока, диффузии, дождя, испарения, моря и таяния |
| Temperature | Оригинальный GPU-шейдер широты, высоты, дня/ночи, переноса ветром |
| Moist | Оригинальный GPU-шейдер источников, потерь, переноса и диффузии влаги |
| Wind | Оригинальный GPU-шейдер глобальных поясов, давления и шумового возмущения |
| Ice | Оригинальный GPU-шейдер замерзания, таяния и обмена |
| Climat | Оригинальная таблица климатических классов и цветов |
| 2D | Оригинальный диагностический display fragment shader для всех восьми полей |
| 3D | Оригинальные land/water fragment shaders, normal map и waterFlow pass; WebGL2 mesh вместо GL tessellation, depth shadows, камера, свет, масштаб высот/поверхности, скорость воды |
| Управление | Веб-панели вместо AntTweakBar/GLFW; все объявленные параметры simulation.cpp, сбросы, новые плиты/возмущение, новый мир/перезапуск |
| Импорт высот | PNG → яркость → диапазон высот → выбранная сетка с переворотом Y; применяется и при последующем движении плит |
| Экспорт | Восемь PNG + metadata.json и лицензия в ZIP, PNG текущего вида; дополнительно lossless Float32 JSON |

Снимки исходников RTWG/RTplatec/libnoise лежат в `vendor/`, без правок upstream (291 файл; thesis PDF и демонстрационные screenshots не
включены как неиспользуемые бинарные материалы). Адаптации — `src/rtwg/`, C ABI — `vendor/rtwg-browser/bridge.cpp`.
Ревизии: RTWG `6cbf782c47c360dcf4bf5ca9b0d1b999d85dac38`, RTplatec
`c75d9605858d1f65bf1cc283834149ab009b2880`, libnoise
`9ce0737b55812f7de907e86dc633724524e3a8e8`.

## Платформенные отличия — не скрывать

- OpenGL 4.3 → WebGL2 / GLSL ES 3.00, RGBA32F float FBO и ping-pong. Требуется
  `EXT_color_buffer_float`. При отсутствии — явное сообщение, не фиктивный fallback.
- Браузер не поддерживает tessellation shaders: высоты/нормали вычисляются на
  ограниченной треугольной сетке до 256×128. Вода, тени и освещение работают,
  но попиксельное совпадение с настольной картинкой не обещается.
- При наличии `OES_texture_float_linear` используется линейная фильтрация,
  иначе nearest. Разные GPU не обязаны давать побитно одинаковые результаты.
- В исходнике Water нижняя граница могла стать отрицательной над сушей.
  В порте глубина ограничена снизу `max(0, sea-ground)`. Деление давления
  защищено от нуля; выходы GPU защищены от NaN/Infinity.
- В исходном C++ `noiseTurbulence` не возвращает объявленный int. При сборке
  добавляется `return 0`. Относительные include нормализуются для memfs.
- Поставляемая libc++ не имеет exception-unwinding: при сборке спецификации
  throw/catch преобразуются, внутренние ошибки trap-ятся на границе JS.
  Входы проверяются до WASM. Формулы и циклы симуляции не заменены JS-аналогами.
- Фиксированный шаг при воспроизведении, без разгона после скрытой вкладки.
  Пауза поля сохраняет его текущий буфер; все проходы читают предыдущее состояние,
  как в RTWG `simulation::update`, swap выполняется после всех проходов.
- Масштабы сетки: 64×32 … 512×256; это глобальная ограниченная карта, **не плотный
  массив метров планеты**. Тектоническая топология RTplatec тороидальная, не
  сферическая модель Земли. Движение плит отключает воду, как в исходном UI.
- Размеры Земли относятся к MIR. Собственные единицы RTWG безразмерны; при
  переносе принято 4000 м/единицу относительно sea_level. Высоты адаптируются
  к диапазону Azgaar 0…100, чрезмерно высокие вершины ограничиваются его пределом.
  Сохраняются целые метры/1×1 м колонка, LOD и интерполяция существующего вида.
- Это исследовательская клеточная симуляция, а не проверенный геологический
  прогноз или метрические реальные данные местности.

## Форматы и сохранность старых карт

`.rtwg.json`: `format=mir-rtwg`, `version=1`, little-endian Float32/base64,
8 RGBA-полей, seed/параметры/счётчики/переключатели. Лимит 32 МиБ, строгая
атомарная проверка размеров/чисел до замены работающего движка. Восстанавливает
поля **без потерь**. Внутренние состояния плит и накопленная waterFlow-анимация
не сериализуются: плиты пересоздаются; точное продолжение тектонической истории
не обещается. По умолчанию загруженный снимок на паузе, тектоника выключена.

PNG — нормализованные 8-битные RGB-каналы. Диапазоны каждого канала указаны в
`metadata.json`; для точных чисел используйте JSON. Север сверху; сырые GPU
строки идут снизу. PNG-высоты импортируются в выбранном пользователем диапазоне.

Обычные карты/слоты/лобби не мигрируют автоматически. Новый RTWG — мастерский
инструмент, не ложная синхронизация двух независимых live-симуляций. Подтверждённый
перенос меняет географию существующего Azgaar-документа и затем передаётся его
обычным механизмом лобби. Климат и реки там заново считает Azgaar. Аннотации
привязаны к координатам и не переселяются на новые материки автоматически.

**Сохраняйте изменённую географию через `.map` в редакторе Azgaar.** Верхний
«Экспорт» MIR экспортирует только seed и размер, не отредактированную карту и
не RTWG-снимок; открытие одного seed не восстановит импортированную географию.

## Лицензии, исходники и пересборка

RTWG — GPLv3, у RTplatec корневой GPLv3 и у унаследованных файлов LGPL-2.1-or-later,
libnoise — LGPL-2.1. Notices и полные тексты включены в интерфейс, web/single и
PNG-архив; условия исходных MIT/CC0 компонентов сохранены. Для объединённой
поставки с RTWG действует GPLv3 — см. `COPYING` и `NOTICE`.

В панели лицензий есть **Скачать полный исходный код MIR**. Это ZIP исходников
приложения, upstream-компонентов, ресурсов и инструкций сборки; обновляется в
`buildWeb/buildSingleHtml`, работает и без сети в `mir.html`. Личные данные,
секреты, `.git`, `node_modules`, готовые web/FMG bundles туда не включаются.

```sh
npm ci --ignore-scripts
npm run fmg:install
npm run rtwg:build       # C++ → WASM, npm-only build toolchain, без OpenGL/DevIL
npm run fmg:build
npm run build
npm run single
npm run test:rtwg
```

`rtwg:build` устанавливает зафиксированный build-only Clang/WASI toolchain через
`npm ci` в `.cache/rtwg-compiler`, собирает оригинальные исходники + C ABI и
кладёт `src/rtwg/rtplatec.wasm`. Compiler не включается в runtime. Его lockfile
и notices — `vendor/rtwg-browser/`; тексты лицензий связанной libc++/wasi-libc
также включены. Для замены/перелинковки LGPL-компонентов измените их исходники
в vendor и повторите `rtwg:build`. Источник архива создаётся из текущего дерева,
поэтому перед распространением следует пересобрать web/single.

`test:rtwg-browser [URL]` требует установленный Playwright Chromium либо
`MIR_CHROMIUM_EXECUTABLE`. Проверяет GPU, snapshot, UI, PNG, мобильные ширины и
подтверждённый перенос в Azgaar. С `file:///…/mir.html` дополнительно проверяет
автономный запуск (прямой импорт dev-модуля в этой ветке теста пропускается).
