# Правила проекта MIR

> Обязательны для всех, кто меняет проект — человека или ИИ-ассистента.
> Читать до начала работы.

---

## 1. Главное правило: ничего лишнего

**Не добавлять ничего, что не было запрошено явно.**

- Нет запроса — нет функции. Никаких «полезных дополнений», «бонусов»
  и «раз уж я здесь, добавлю ещё…».
- Не придумывать новые экраны, кнопки, модальные окна, настройки, режимы,
  анимации, звуки, зависимости и «пасхалки».
- Кажется, что чего-то не хватает — сначала **спросить**, потом делать.
- Каждая сущность в проекте должна ссылаться на конкретный запрос владельца.
- Правило действует и в обратную сторону: не удалять и не «упрощать»
  то, что уже было запрошено.

## 2. Основная структура (менять нельзя без запроса)

1. Кнопки главного меню — **строго по центру экрана**: «Мастер» и «Игрок».
2. Кнопка настроек — **шестерёнка в левом верхнем углу**, всегда на месте.
3. Лобби друзей и приглашений — **панель справа** (как в CS2), с аватарками.
4. Всё запускается **одним файлом** `index.html`, без сборки и сервера.

## 3. Дизайн

Ориентир — тёмная тема **arena.ai**. Токены живут в `:root` внутри
`index.html`; новые цвета, радиусы и размеры вне этого списка не вводятся.

### Палитра (только тёмно-серые, белый и функциональные статусы)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--surface-primary` | `#252523` | фон экрана |
| `--surface-secondary` | `#2c2b28` | панели, карточки, вторичные кнопки |
| `--surface-tertiary` | `#1b1a19` | поля ввода, утопленные блоки |
| `--surface-floating` | `#221f1b` | модальные окна, уведомления |
| `--border-faint` / `--border-medium` / `--border-strong` | `#413d39` / `#524c47` / `#5f5a54` | рамки |
| `--text-primary` … `--text-faint` | `#f4f0eb` → `#6f6960` | четыре ступени текста |
| `--cta` / `--on-cta` | `#fcfaf8` / `#252523` | главная кнопка |
| `--positive` / `--negative` | `#41be4b` / `#f25550` | только статусы и опасные действия |

Декоративного цвета в интерфейсе нет. Зелёный — исключительно индикатор
«в сети», красный — только подсветка опасного действия при наведении.
Никаких градиентов, свечений, неона и «геймерских» эффектов.

### Радиусы и размеры

- Радиусы: `4` (метки) → `6` (кнопки, поля) → `8` (карточки, строки)
  → `12` (панели, модальные окна) → `pill` (переключатели, точки).
- Высоты элементов: `28` (мелкая кнопка), `32` (кнопка, поле, иконка),
  `36` (аватар профиля, шестерёнка), `44` (главные кнопки меню и строки лобби).
- Отступы кратны 2 px, основной шаг — 6/8/12/16.

### Иконки

- Только линейные SVG в стиле lucide: `viewBox="0 0 24 24"`, `fill="none"`,
  `stroke="currentColor"`, `stroke-width="1.5"`, скруглённые концы.
- Размер 16 px (18 px — шестерёнка). Набор лежит в `iconPaths` в `index.html`.
- **Эмодзи и растровые иконки запрещены.**

### Типографика

- Интерфейс — `Basel Grotesk` (латиница) + `Inter` (кириллица), оба локально
  в `fonts/`. Именно такой стек использует arena.ai, поэтому русский текст
  не проваливается в системный шрифт.
- Шрифты arena.ai **не содержат кириллицы** — при добавлении новых начертаний
  это нужно проверять, иначе типографика снова расползётся.
- Логотип `MIR` — `Martina Plantijn Light` (только латиница).
- Веса: 400 — текст, 500 — заголовки и кнопки. Жирнее не используем.

## 4. Код

- Один файл `index.html`: разметка, стили и логика. Без сборки и зависимостей.
- Новый интерфейс собирается из уже существующих классов
  (`.btn`, `.icon-btn`, `.input`, `.row`, `.block`, `.pill`, `.avatar`, `.modal`).
- Пользовательские данные экранируются через `escapeHTML`.
- Не заменять рабочую логику статичными муляжами.

## 5. Что сейчас входит в проект (по запросам владельца)

1. **Главное меню**: «Мастер», «Игрок», шестерёнка настроек.
2. **Аккаунты**: регистрация, вход, выход, хранение в `localStorage`.
3. **Друзья**: заявки по логину, принятие и отклонение, статус «в сети».
4. **Комнаты**: создание мастером, приглашения друзей, вход и выход.
5. **Лобби справа в стиле CS2**: профиль, комната, заявки, приглашения, друзья.
6. **Настройки**: переключатель «меньше анимации».

Всё, что выходит за этот список, добавляется **только по новому запросу**.
