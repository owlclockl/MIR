# Правила проекта MIR

1. Не добавлять лишние функции, экраны, эффекты, режимы или декор без прямого запроса.
2. Сохранять основную структуру меню: основные кнопки по центру, настройки — шестерёнкой в левом верхнем углу.
3. Дизайн держать минималистичным: тёмные серые тона, белый текст, спокойные SVG-иконки.
4. Любой новый функционал должен визуально совпадать с текущей системой компонентов.
5. Не заменять полноценную рабочую логику статичными муляжами.
