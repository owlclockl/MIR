# Правила работы над проектом «МИР»

> Эти правила обязательны для любого, кто вносит изменения в проект
> (человек или ИИ-ассистент). Читать до начала работы.

## 1. Главное правило: ничего лишнего

**Не добавлять ничего, что не было запрошено явно.**

- Нет запроса — нет функции. Никаких «полезных дополнений», «бонусов»,
  «раз уж я здесь, добавлю ещё…».
- Не придумывать новые экраны, кнопки, модальные окна, таблицы БД,
  API-эндпоинты, зависимости, анимации, звуки и «пасхалки».
- Если кажется, что чего-то не хватает — сначала **спросить**, потом делать.
- Любая новая сущность должна ссылаться на конкретный запрос заказчика.

## 2. Правила дизайна

- Минимализм: тёмно-серые, чёрные и белые тона (ориентир — arena.ai).
  Никаких неоновых, золотых, «геймерских» градиентов и свечений.
- Иконки — только минималистичные линейные SVG (stroke 1.6–1.8).
  **Эмодзи запрещены** в интерфейсе.
- Кнопки главного меню — строго по центру экрана.
  Кнопка настроек (шестерёнка) — в левом верхнем углу.
- Шрифт Inter/system, спокойные радиусы, тонкие рамки
  `rgba(255,255,255,.07)`, ховеры — только смена фона/рамки.
- Цвет допускается только для деструктивных действий (приглушённый красный).

## 3. Что сейчас входит в проект (по запросам заказчика)

1. **Главное меню**: «Мастер», «Игрок», вход по коду комнаты, шестерёнка настроек.
2. **Система аккаунтов**: регистрация, вход, демо-аккаунты, профиль,
   аватары и рамки, ники с тегами.
3. **Друзья**: список, поиск, запросы в друзья, статусы присутствия (WebSocket).
4. **Комнаты и приглашения**: создание комнаты Мастером, список открытых
   комнат, вход по коду, приглашения друзей, готовность, кик, выход.
5. **Правая панель в стиле CS2**: лобби со слотами и аватарками, друзья,
   приглашения — реальные данные с сервера, не муляж.

Всё, что выходит за этот список, добавляется **только по новому запросу**.

## 4. Запуск

- `node start.js` — установка зависимостей, сервер и открытие браузера одним файлом.
- `npm run preview` — сборка автономного `index.html` для просмотра дизайна.
