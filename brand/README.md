# Бренд-система The civilization of the sages

Статическая страница-каталог: знак, редакции логотипа, палитра, типографика,
компоненты и правила текста. Открывается без сборки:

- в режиме разработки — `npm run dev`, затем `/brand/`;
- как файл — `brand/index.html`, но картинки по путям `/logo.svg` в этом
  случае браузер не найдёт: их раздаёт только веб-сервер (Vite, Cloudflare,
  `server/serve.mjs`).

Проверка: `npm run test:brand` — сверяет файлы, палитру с `src/style.css`,
контраст, геометрию знака и шрифты.

## Что здесь лежит

| Файл | Назначение |
| --- | --- |
| `index.html` | сама книга: восемь глав, переключатель поверхности, копирование hex |
| `brand.css` | оформление книги; токены повторяют `src/style.css` |
| `brand.js` | поверхность плашек, копирование цвета, подсветка текущей главы |
| `fonts/` | ужатые до латиницы и кириллицы Manrope 700 и Inter 400–600 |

Логотипы и знак живут в `public/`: `logo.svg`, `logo-ink.svg`,
`logo-stacked.svg`, `logo-stacked-ink.svg`, `logo-sages.svg`,
`logo-sages-ink.svg`, `logo-mark.svg`, `logo-mark-ink.svg`, `logo-mono.svg`.
PNG-иконки приложения строятся из той же геометрии командой `npm run icons`.

## Правила, которые нельзя обойти молча

1. Геометрия знака одна: кольцо r 8.2, точка r 2.4, риски по сторонам света
   на сетке 24 × 24. Меняется знак — меняются `logo-mark.svg`,
   `icon('sigil')`, PNG-иконки и все логотипы.
2. Название в логотипах — контуры, не текст. Иначе на чужой машине без
   Manrope логотип «поедет».
3. На бумаге используются ink-файлы (`#24362f`, `#7a5c26`), а не экранные
   `#c2d9c9` и `#d8c184`.
4. Цвета, отступы, радиусы и высоты берутся из `src/style.css`; страница
   обязана совпадать с интерфейсом, а не жить своей палитрой.

## Шрифты

Manrope и Inter распространяются по SIL Open Font License 1.1. Тексты
лицензий лежат рядом: `fonts/LICENSE-Manrope.txt` и `fonts/LICENSE-Inter.txt`.
Файлы ужаты из пакетов `@fontsource/manrope` и `@fontsource/inter` (версия
5.3.0) до нужных алфавитов; сами шрифты в репозиторий не входят.

Логотипы переведены в кривые теми же начертаниями Manrope 700 и Inter 600.
Если понадобится новая редакция с другим текстом, буквы снова
превращаются в контуры — правкой в векторном редакторе, а не установкой
шрифта «рядом с файлом».
