# Правила для ИИ-ассистентов

Полные правила — в [PROJECT_RULES.md](./PROJECT_RULES.md). Прочитайте их
до первого изменения файлов.

## Коротко

1. **Не добавлять ничего, что не запрошено явно** — ни функций, ни экранов,
   ни настроек, ни эффектов, ни зависимостей, ни «улучшений заодно».
   Сомневаетесь — спросите владельца проекта, не делайте на своё усмотрение.
2. **Не ломать основную структуру:** кнопки меню — по центру экрана,
   шестерёнка настроек — в левом верхнем углу, лобби друзей — справа (как в CS2),
   запуск — одним файлом `index.html`.
3. **Дизайн — тёмная тема arena.ai:** тёмно-серые тона, белый текст,
   линейные SVG-иконки (stroke 1.5), без цветного декора и без эмодзи.
   Используйте только токены из `:root` в `index.html`.
4. **Не заменять рабочую логику муляжами** и не удалять уже запрошенное.
