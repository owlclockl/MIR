# MIR

Минималистичное стартовое меню игры в тёмных серых/белых тонах.

## Как посмотреть

Откройте `index.html` в браузере. Это самодостаточный файл для просмотра меню и проверки аккаунтов, друзей, комнат и приглашений.

## Что реализовано

- меню с центральными кнопками **Мастер** и **Игрок**;
- кнопка настроек-шестерёнка в левом верхнем углу;
- SVG-иконки без лишнего визуального шума (стиль lucide);
- оформление повторяет тёмную тему arena.ai: тёплый графит `#252523`, кремовый текст, радиусы 4px у кнопок, зелёный хайлайт;
- шрифты как на arena.ai: Basel Grotesk (интерфейс) и Martina Plantijn Light (серифные заголовки), подключены локально из `fonts/`;
- локальная система аккаунтов: регистрация, вход, выход;
- хранение аккаунтов, друзей, заявок, комнат и приглашений в `localStorage` браузера;
- правый блок лобби в стиле CS2: профиль, друзья, приглашения, текущая комната;
- комнаты мастера и приглашения друзей.

## Важно

Система аккаунтов полностью рабочая в рамках одного браузера и сохраняет данные локально. Для сетевых аккаунтов между разными устройствами потребуется отдельный сервер и база данных — это не добавлялось, чтобы не выходить за рамки запроса на запуск одним файлом.

## Правило проекта

Не добавлять лишние функции, экраны, эффекты или декор без прямого запроса владельца проекта. Сохранять минимализм, понятную структуру и тёмную серо-белую палитру.
