# The civilization of the sages

Минималистичное главное меню веб-игры: тёмная тема, острые углы, волосяные линии.

Это полноценное приложение (PWA): ставится на ПК и телефоны, работает офлайн.
Внутри — аккаунты, аватарки, друзья с заявками и код-приглашения. ПК может
быть «сервером» для друзей по Wi-Fi **и через интернет** — внешние серверы
для игры не нужны вообще; наружу выходит только временный туннель.

> История проекта — в [`CHANGELOG.md`](CHANGELOG.md), договорённости по стилю и
> правила работы — в [`AGENTS.md`](AGENTS.md). Меняете что-то — допишите запись в журнал.

## Установить как приложение

Откройте меню по **https** (туннель `--public` или GitHub Pages — см. ниже) и:

- **ПК (Chrome/Edge)** — кнопка «Установить» в адресной строке справа.
- **Android (Chrome)** — меню ⋮ → «Установить приложение» / «Добавить на
  главный экран».
- **iPhone/iPad (Safari)** — «Поделиться» → «На экран "Домой"».

После установки — отдельное окно без браузерной рамки, иконка с фирменным
знаком, запуск офлайн. Примечание: по голому http в локальной сети браузеры
установку не дают (техническое требование к service worker) — как сайт всё
равно работает.

## ПК как сервер для друзей

```bash
npm run share
```

Кроме раздачи меню, поднимается **хаб общих аккаунтов**: друзья, открывшие
сайт по адресу из той же Wi-Fi, автоматически подключаются к нему и видят
общие аккаунты, заявки, друзей и коды-приглашения. Регистрируйте каждого на
его устройстве — и добавляйте друг друга по имени или коду.

- Данные хаба — файл `data/mir-hub.json` на вашем ПК; удалите его, чтобы
  начать с чистого листа.
- Пароли по сети не ходят: хеш SHA-256 считается на устройстве игрока.
- Хаб можно выключить: `node serve.mjs --no-hub` (тогда у каждого устройства
  свои локальные аккаунты, как раньше).

## Аккаунты и друзья

Кнопка **«Войти»** в правом верхнем углу открывает окно входа/регистрации.

- **Аватарка** — в профиле (клик по имени в шапке): загрузка картинки с
  предпросмотром, кадрирование по центру до 96×96.
- **Добавить друга** — кнопка «+» в панели друзей: поиск по имени среди
  аккаунтов этого устройства. Заявки приходят блоком «Заявки» в ту же панель.
- **Код-приглашение** — в подвале панели и в профиле: передайте его другу,
  он введёт код у себя, и вы сразу станете друзьями друг у друга.

Проверить в одиночку: зарегистрируйте два аккаунта и переключайтесь между
ними через «Выйти» / «Войти». В двух вкладках тоже работает — список
синхронизируется сам. Если открыто по сети с `npm run share`, аккаунты
общие для всех, кто подключился (см. «ПК как сервер»).

## Запуск

```bash
npm install
npm run dev
```

### Windows — двойным кликом, без команд

- **`СБОРКА.bat`** — интерактивное меню сборки с выбором формата:
  - `[1]` **Веб-версия** (`dist/` и однофайловый `mir.html`).
  - `[2]` **Windows-установщик (`MIR-Setup.exe`)** — автономный установщик игры. При запуске создаёт ярлыки на рабочем столе и в меню «Пуск» с фирменной иконкой, запускает игру в чистом окне без браузерной строки.
  - `[3]` **Android-установщик (`MIR.apk`)** — готовый подписанный APK-пакет для телефонов и планшетов.
  - `[4]` **Всё сразу** — собирает все форматы за пару секунд.
  Полученными файлами (`MIR-Setup.exe` и `MIR.apk`) можно делиться с друзьями, просто перекидывая их через Telegram, Discord, VK или флешку!
- **`ИГРАТЬ-С-ДРУЗЬЯМИ.bat`** — собирает свежую версию, поднимает сервер
  с общим хабом и сам открывает игру в браузере. Спросит, кого звать:
  друзей из той же Wi-Fi сети или из интернета (тогда поднимет `--public`-туннель).
  Пока окно открыто — ссылки работают.

## Команды сборщика

```bash
npm run build:exe    # собрать Windows-установщик (MIR-Setup.exe)
npm run build:apk    # собрать Android-установщик (MIR.apk)
npm run build:all    # собрать всё сразу (Web + .exe + .apk)
npm run single       # собрать mir.html
```

## Показать друзьям

```bash
npm run share
```

Команда собирает продакшн-версию и поднимает сервер. В терминале появятся два адреса:

```
  На этом компьютере   http://localhost:4173/
  Для друзей в той же сети Wi-Fi:
                       http://192.168.1.42:4173/
```

Второй адрес и есть ссылка для друзей — **но только для тех, кто сидит в той же
сети Wi-Fi**. Пока команда работает, сайт доступен; закрыли терминал — ссылка умерла.

Полезное:

```bash
npm run serve                  # раздать уже собранный dist/, без пересборки
node serve.mjs . --port 8080   # другой каталог и порт
node serve.mjs --help          # все флаги
```

### Ссылка для друзей из интернета

Адрес `192.168.*` снаружи не открывается — нужен либо туннель, либо хостинг.

**Туннель — быстро, пока компьютер включён:**

```bash
npm run share:public
```

Поднимает временную `https://…loca.lt` ссылку через `npx localtunnel`.
Учтите: первому посетителю localtunnel показывает страницу с запросом пароля —
это ваш внешний IP, подсмотреть можно на <https://loca.lt/mytunnelpassword>.
Если туннель не поднимется, локальный сервер продолжит работать.

**GitHub Pages — постоянная ссылка, компьютер выключать можно:**

Репозиторий уже на GitHub, поэтому достаточно собрать и выложить `dist/`.
В настройках репозитория: *Settings → Pages → Source → GitHub Actions*,
затем добавить workflow, который делает `npm ci && npm run build` и публикует
`dist/`. Получится адрес вида `https://owlclockl.github.io/MIR/`.

## Запуск одним файлом

Всё меню собрано в один самодостаточный файл `mir.html` (HTML + CSS + JS внутри).
Просто откройте его двойным кликом в браузере — ни Node, ни установки зависимостей
не нужно. Этот же файл удобно отправить другу в мессенджере.

Пересобрать после правок в `index.html` / `src/`:

```bash
npm run single   # или: node build-single.mjs
```
