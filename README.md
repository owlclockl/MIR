# The civilization of the sages

Минималистичное главное меню веб-игры: тёмная тема, острые углы, волосяные линии.

Меню статично — это только интерфейс. Кнопки настоящие (фокус, наведение, нажатие),
но за ними намеренно нет ни логики, ни заглушек-уведомлений.

## Запуск

```bash
npm install
npm run dev
```

Иконки основаны на [Lucide](https://lucide.dev/) (ISC License).
Шрифты — Inter и Manrope, подключаются с Google Fonts; без сети подхватывается системный шрифт.

## Запуск одним файлом

Всё меню собрано в один самодостаточный файл `mir.html` (HTML + CSS + JS внутри).
Просто откройте его двойным кликом в браузере — ни Node, ни установки зависимостей не нужно.

Пересобрать файл после правок в `index.html` / `src/`:

```bash
npm run single   # или: node build-single.mjs
```

## Структура

| Файл              | Назначение                                      |
| ----------------- | ----------------------------------------------- |
| `index.html`      | каркас страницы, мета-теги, подключение шрифтов |
| `src/style.css`   | вся вёрстка и оформление                        |
| `src/main.js`     | разметка меню и данные списка друзей            |
| `mir.html`        | собранная однофайловая версия                   |
| `preview.svg`     | статичный макет экрана                          |
