# MIR

Минималистичное главное меню веб-игры.

## Запуск

```bash
npm install
npm run dev
```

Иконки основаны на [Lucide](https://lucide.dev/) (ISC License).

## Запуск одним файлом

Всё меню собрано в один самодостаточный файл `mir.html` (HTML + CSS + JS внутри).
Просто откройте его двойным кликом в браузере — ни Node, ни установки зависимостей не нужно.

Пересобрать файл после правок в `index.html` / `src/`:

```bash
npm run single   # или: node build-single.mjs
```
