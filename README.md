# МИР

Ролевая онлайн-игра: главное меню, система аккаунтов, друзья, комнаты и
лобби в правой панели в стиле CS2.

## Запуск

```bash
node start.js     # зависимости + сервер + браузер, одним файлом
npm run preview   # собрать автономный index.html для просмотра дизайна
```

Перед любыми правками прочитайте [ПРАВИЛА.md](./ПРАВИЛА.md).
