MIR interface sounds

Source: UI SFX — open-source library of interface sound effects
        https://github.com/romainsimon/uisfx · npm package `uisfx`
        version 0.4.0, pack «Minimal» (dry, precise, almost invisible).

Files in this folder are copies of these library files:

  click.mp3      ← sounds/minimal/press.mp3
  success.mp3    ← sounds/minimal/success.mp3
  message.mp3    ← sounds/minimal/notification.mp3
  error.mp3      ← sounds/minimal/error.mp3
  open.mp3       ← sounds/minimal/open.mp3
  close.mp3      ← sounds/minimal/close.mp3
  toggle-on.mp3  ← sounds/minimal/toggle-on.mp3
  toggle-off.mp3 ← sounds/minimal/toggle-off.mp3

To replace the whole set with another pack (the library ships 12 of them:
minimal, soft, glass, arcade, mechanical, organic, dreamy, scifi, rubber,
cinematic, studio, zen), run:

  npm run sounds -- glass

The script `scripts/sounds.mjs` downloads the same version of the package
from npm, takes the four files and refreshes this folder. The version and
the list of files are written at the top of that script.

Earlier revisions of the project used four short tones generated by
additive synthesis specifically for MIR (also CC0). They are replaced by
these files and are not part of the project anymore.
