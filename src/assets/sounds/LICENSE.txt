MIR menu sound effects

Source: UI SFX — open-source library of interface sound effects
        https://github.com/romainsimon/uisfx · npm package `uisfx`
        version 0.4.0, pack «Arcade» (game-like menu feedback).

Files in this folder are copies of these library files:

  click.mp3         ← sounds/arcade/press.mp3
  success.mp3       ← sounds/arcade/success.mp3
  message.mp3       ← sounds/arcade/notification.mp3
  error.mp3         ← sounds/arcade/error.mp3
  open.mp3          ← sounds/arcade/open.mp3
  close.mp3         ← sounds/arcade/close.mp3
  toggle-on.mp3     ← sounds/arcade/toggle-on.mp3
  toggle-off.mp3    ← sounds/arcade/toggle-off.mp3
  select.mp3        ← sounds/arcade/select.mp3
  back.mp3          ← sounds/arcade/back.mp3
  unlock.mp3        ← sounds/arcade/unlock.mp3
  connect.mp3       ← sounds/arcade/connect.mp3
  volume-change.mp3 ← sounds/arcade/volume-change.mp3

To replace the whole set with another pack (the library ships 12 packs:
minimal, soft, glass, arcade, mechanical, organic, dreamy, scifi, rubber,
cinematic, studio, zen), run:

  npm run sounds -- glass

The script `scripts/sounds.mjs` downloads the same version of the package
from npm, takes these thirteen cues and refreshes this folder. The package
version, selected pack and cue mapping are in that script.
